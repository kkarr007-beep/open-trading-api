감사기록

바탕화면의 '감사기록' 아이콘을 누르면 프로그램 창이 뜹니다. 창을 닫으면 프로그램도 끝납니다.

· 이 컴퓨터에서만 쓰는 프로그램입니다. 다른 컴퓨터에서는 접속되지 않고, 인터넷으로 내용을 보내지 않습니다.
· 기록과 자료가 있는 곳: 내 사용자 폴더 아래 '감사기록'
    data   기록 (audit.db)
    files  자료 원문
    inbox  수집함 - 여기에 문서를 넣으면 자동으로 가져갑니다 (시작 메뉴의 '수집함 폴더')
    backup 백업
· 창은 이 프로그램 자체의 것입니다. Edge나 Chrome이 없어도 뜹니다.
  창에 파일을 끌어다 놓으면 수집함으로 들어가고, 건 상세 화면에 놓으면 그 건에 붙습니다.
  F5 새로 고침 · Alt+←/→ 앞뒤 화면 · Ctrl +/- 글자 크기 · Ctrl+K 전체 찾기
· 암호화된 문서는 포털에 로그인된 상태에서 워드, 엑셀, 파워포인트, 한글이 열어 읽습니다.
· 지우기: 시작 메뉴의 '감사기록 제거' 또는 설정 > 앱. 기록과 자료 폴더는 지우지 않습니다.

함께 들어 있는 Java 실행 환경(jre 폴더)과 화면 엔진(fx 폴더)은 OpenJDK, OpenJFX입니다. 사용 조건은 jre\legal 폴더에 있습니다.

# run7 변경 설명

대표님 요청으로 화면을 다시 짜고, 건 상세에서 첨부 파일을 눌러 열 수 있게 했습니다. 설치 절차와 데이터 위치는 그대로입니다.

## 화면

- 색, 간격, 모서리, 그림자를 CSS 변수로 두었습니다. 라이트와 다크가 있고, 헤더에서 라이트·다크·시스템을 고릅니다. 선택은 그 브라우저에만 저장되며, 첫 화면이 깜빡이지 않도록 스타일보다 먼저 적용합니다.
- 글꼴은 설치되어 있으면 Pretendard, 없으면 맑은 고딕과 Segoe UI입니다. 폰트 파일을 넣지 않았고 외부 주소도 쓰지 않습니다.
- 넓은 화면에서는 왼쪽 메뉴와 본문이 나란히 놓입니다. 좁은 화면에서는 메뉴가 위로 올라가고 표는 상자 안에서만 가로로 움직입니다. 폭을 고정하지 않았습니다.
- 할 일 화면 위에 건수 카드를 두었습니다.

## 첨부 파일

- 파일이 남아 있는 자료 행을 누르면, PDF·이미지·텍스트는 창 안에서 미리보고 그 외는 내려받습니다. 행에 마우스를 올리거나 키보드로 이동하면 눌 수 있음이 보입니다. Enter도 됩니다.
- 서버는 파일을 실행하지 않습니다. 권한을 확인한 뒤 내용의 앞부분을 보고, HTML·SVG처럼 스크립트가 될 수 있는 파일은 미리보기 없이 내려받기만 합니다.
- 응답에는 `Content-Disposition`, `X-Content-Type-Options: nosniff`, 스크립트를 막는 CSP와 sandbox를 붙입니다.
- 삭제되었거나 복구 대조로 숨긴 파일은 열지 않습니다. 열람과 내려받기는 이력 체인에 `열람`으로 남습니다.
- 나스카 암호문은 풀지 않습니다. 사용자 PC에서 여는 안내 문장은 그대로입니다.

## 유지한 것

역할, 보존, 보류, 삭제 작업, 무결성 잠금의 503 읽기 전용, 백업 매니페스트, 원장, CSRF, 화면 랜드마크는 그대로입니다.

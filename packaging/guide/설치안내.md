# 감사기록 설치 안내

회사 서버 한 대에 설치하고, 같은 내부망의 다른 PC는 브라우저로만 들어옵니다.
서버가 켜지면 프로그램이 자동으로 실행됩니다. 아무도 로그인하지 않아도 계속 돕니다.

---

## 0. 가져갈 것

USB에 아래 세 조각만 담아 가면 됩니다. 인터넷이 없어도 설치됩니다.

```
audit-record-win-x64.zip.part00
audit-record-win-x64.zip.part01
audit-record-win-x64.zip.part02
```

회사 PC에서 명령 프롬프트를 열고 세 조각을 하나로 합칩니다.

```bat
copy /b audit-record-win-x64.zip.part00 + audit-record-win-x64.zip.part01 + audit-record-win-x64.zip.part02 audit-record-win-x64.zip
```

합친 파일이 온전한지 확인합니다. 아래 값과 같아야 합니다.

```powershell
Get-FileHash -Algorithm SHA256 .\audit-record-win-x64.zip
```

```
B3555B598D66B6F2BF9F0DD153481A21312ECEB9935023B870AEF18A4C95EB37
```

### 서버에 필요한 것

| 항목 | 필요한 값 |
|------|-----------|
| 운영체제 | Windows 10/11 또는 Windows Server, **64비트** |
| 디스크 | 설치에 약 250MB. 자료가 쌓일 공간은 따로 |
| 권한 | 그 PC의 **관리자 계정** (서비스 등록에 필요) |
| .NET | **설치하지 않습니다.** 프로그램 안에 들어 있습니다 |
| 인터넷 | **필요 없습니다** |

### 미리 정해 갈 것

- 서버의 **내부 IP 주소** (명령 프롬프트에서 `ipconfig`)
- 파트원에게 알려 줄 **접속 비밀번호** (12자 이상)
- 서버로 쓸 PC는 개인 업무 PC와 겸하지 않습니다

---

## 1. 압축 풀기

`C:\감사기록` 처럼 전용 폴더에 통째로 풉니다. 풀고 나면 이렇게 보여야 합니다.

```
C:\감사기록\
  app\        프로그램 본체
  data\       audit.db 가 여기 생깁니다
  files\      첨부 파일이 여기 쌓입니다
  backup\     내부 백업
  app-keys\   로그인 키, 인증서
  config\     설정 예시
  scripts\    간편설치.cmd 가 여기 있습니다
  guide\      안내 문서
```

> `app`, `data`, `scripts` 가 **나란히** 있어야 합니다. 한 단계 더 들어가 있으면 설치가 멈춥니다.

### 차단 해제

인터넷에서 받은 파일로 표시되어 있으면 스크립트가 거부됩니다. 관리자 PowerShell에서 한 번만 풉니다.

```powershell
Get-ChildItem -Path C:\감사기록 -Recurse | Unblock-File
```

---

## 2. 설치 (한 번만)

`C:\감사기록\scripts\간편설치.cmd` 를 **오른쪽 눌러 → 관리자 권한으로 실행**합니다.

> 그냥 두 번 눌러도 됩니다. 관리자 권한을 스스로 요청합니다.

### 이 서버에서만 쓸 때

```bat
간편설치.cmd
```

### 다른 PC도 들어오게 할 때 (대부분 이쪽)

서버 내부 IP가 `10.1.2.10` 이라면:

```bat
간편설치.cmd -Listen 10.1.2.10
```

### 인증서(HTTPS)까지 쓸 때

내부 CA에서 받은 PFX를 `C:\감사기록\app-keys\audit.pfx` 에 두고:

```bat
간편설치.cmd -Listen 10.1.2.10 -Pfx C:\감사기록\app-keys\audit.pfx
```

PFX에 암호가 있으면 설치 **전에** 암호 파일을 만들어 둡니다.

```powershell
$secure = Read-Host -AsSecureString 'PFX 암호'
$ptr = [Runtime.InteropServices.Marshal]::SecureStringToBSTR($secure)
try {
  $plain = [Runtime.InteropServices.Marshal]::PtrToStringBSTR($ptr)
  [IO.File]::WriteAllBytes('C:\감사기록\app-keys\cert-password.txt', [Text.Encoding]::UTF8.GetBytes($plain))
} finally { [Runtime.InteropServices.Marshal]::ZeroFreeBSTR($ptr) }
```

### 간편설치가 알아서 하는 일

1. `data`, `files`, `backup`, `app-keys` 폴더 만들기
2. 서비스 계정에 그 폴더 권한 주기
3. **Windows 서비스로 등록** — 서버가 켜지면 자동 실행
4. 서비스가 멈추면 다시 시작하도록 설정
5. 방화벽 열기 (`-Listen` 을 준 경우에만, 도메인·개인 네트워크만)
6. **바탕화면에 `감사기록` 아이콘** 만들기
7. 서비스 시작하고 브라우저로 설치 화면 열기

---

## 3. 접속 비밀번호 정하기

설치가 끝나면 서버 브라우저에 설치 화면이 저절로 열립니다.
열리지 않으면 서버에서 직접 `http://127.0.0.1:47321` 을 엽니다.

1. **우리 파트 이름** — 화면 위에 보일 이름 (예: 감사파트). 실명은 적지 않습니다
2. **접속 비밀번호** — 12자 이상. 이 값을 파트원에게 알려 줍니다
3. **비밀번호 확인**
4. `설치하고 시작하기`

> 이 화면은 **서버의 127.0.0.1 에서만** 열립니다. 다른 PC에서 열면 거부합니다.
> 한 번 마치면 사라집니다.

관리자 계정이 함께 만들어집니다. 로그인 이름은 `admin` 입니다.

---

## 4. 파트원에게 알려 줄 것

딱 두 가지입니다.

```
주소     http://10.1.2.10:47321      (서버 IP와 포트)
비밀번호  설치 때 정한 값
```

파트원은 그 주소를 열고 **비밀번호만 눌러** 들어옵니다. 로그인 이름은 묻지 않습니다.

---

## 5. 마무리 설정

### 5-1. 보존 기준 확인 (꼭 해야 자동 삭제가 돕니다)

관리 화면 → **보존·백업 기준** → 내용을 읽고 `정책 확인`.
이걸 누르기 전에는 연한이 지나도 자동 삭제가 돌지 않습니다.

### 5-2. 첨부 파일 공유 경로

자료 화면에 적히는 UNC 경로입니다. 설정 전에는 "아직 설정되지 않았습니다"로 보입니다.

1. `C:\감사기록\files` 를 감사파트 그룹에 **읽기 전용**으로 공유
2. `C:\감사기록\app\appsettings.Production.json` 의 `FilesShareUnc` 에 그 경로를 적기
   예: `"FilesShareUnc": "\\\\audit-server\\audit-files"`
3. `Restart-Service AuditRecord`

> `data`, `backup`, `app-keys` 는 **공유하지 않습니다.**

### 5-3. 계정 더 만들기 (역할을 나눌 때)

관리 화면 → **계정** → 표시 이름, 로그인 이름, 역할을 정해 만듭니다.
임시 비밀번호는 그 화면에 **한 번만** 보입니다. 그때 옮겨 적으세요.

| 역할 | 할 수 있는 일 |
|------|---------------|
| 담당 | 건 등록, 조치요구, 회신 기록, 자료 추가 |
| 파트장 | 담당 + 결과 확정·취소·종결, **징계기록 열람과 등재** |
| 관리자 | 파트장 + 계정, 백업, 삭제 보류, 연한 전 파일 삭제 |

계정으로 들어갈 때는 로그인 화면의 `계정 이름으로 들어가기` 를 씁니다.

### 5-4. 백업 폴더 (권장)

같은 디스크 말고 다른 디스크를 쓰는 편이 낫습니다.
`appsettings.Production.json` 의 `BackupAllowRoot` 에 `"D:\\audit-backup"` 처럼 적고 서비스를 다시 시작합니다.
백업은 관리 화면에서 관리자가 직접 실행합니다. 인터넷 백업은 없습니다.

---

## 6. 잘 되는지 확인

| 확인할 것 | 방법 | 정상 |
|-----------|------|------|
| 서비스가 도는가 | `Get-Service AuditRecord` | `Running` |
| 자동 실행인가 | `Get-Service AuditRecord \| Select StartType` | `Automatic` |
| 서버에서 열리는가 | 바탕화면 `감사기록` 아이콘 | 로그인 화면 |
| **다른 PC에서 열리는가** | 그 PC 브라우저에서 내부망 주소 | 로그인 화면 |
| 비밀번호로 들어가지는가 | 비밀번호 입력 | 할 일 화면 |
| **재부팅해도 도는가** | 서버 재시작 후 다른 PC에서 접속 | 로그인 화면 |

마지막 두 줄은 꼭 직접 해 보세요. 제가 확인하지 못한 부분입니다.

### 사람이 해야 하는 확인 하나

나스카로 암호화된 파일 하나를 `files` 폴더에 넣고, 담당자 PC에서 포털 로그인 후 열리는지 봅니다.
프로그램은 암호를 풀지 않고 내용을 읽지 않습니다. 열림 여부는 나스카가 판단합니다.

---

## 7. 평소 다루기

```powershell
Get-Service AuditRecord          # 상태 보기
Restart-Service AuditRecord      # 설정을 고친 뒤
Stop-Service AuditRecord         # 잠시 멈추기
Start-Service AuditRecord        # 다시 시작
```

설정 파일을 고치면 **반드시** 서비스를 다시 시작해야 반영됩니다.

### 접속 비밀번호 바꾸기

설정 화면 → **접속 비밀번호** → 지금 값, 새 값, 확인 → `접속 비밀번호 바꾸기`.
바꾼 뒤에는 새 비밀번호만 들어옵니다. 관리자만 바꿀 수 있습니다.

---

## 8. 막혔을 때

| 증상 | 볼 곳 |
|------|-------|
| 설치가 바로 멈춤 | `app`, `data`, `scripts` 가 나란히 있는지 |
| 스크립트가 거부됨 | 위 1번의 `Unblock-File` |
| 서비스가 안 올라옴 | `C:\감사기록\data\startup-error.log` 한 줄 |
| 다른 PC에서 안 열림 | 방화벽, `BindAddress` 가 서버 IP인지, 같은 내부망인지 |
| 인증서 경고 | PFX의 SAN에 그 IP나 서버 이름이 들어 있는지 |
| 비밀번호가 안 먹음 | 5번 틀리면 15분 잠깁니다. 기다렸다 다시 |

로그는 `Get-EventLog -LogName Application -Source AuditRecord -Newest 20` 으로도 봅니다.

## 9. 지우기

```powershell
C:\감사기록\scripts\uninstall.ps1
```

서비스 등록, 방화벽 규칙, 바탕화면 아이콘만 지웁니다.
`data`, `files`, `backup`, `app-keys` 는 **그대로 둡니다.** 기록은 남습니다.

## 10. 제가 확인하지 못한 것

정직하게 적습니다. 이 꾸러미는 Linux에서 만들고 시험했습니다.

- **Windows에서 실행해 보지 않았습니다.** `간편설치.cmd`, 서비스 등록, 권한 설정, 방화벽, 바탕화면 아이콘은 Windows에서 돌려 본 적이 없습니다.
- 재부팅 후 자동 실행을 확인하지 못했습니다.
- 다른 PC 브라우저에서 접속해 보지 못했습니다.
- 내부 CA 인증서와 PFX를 써 보지 못했습니다.
- 내려받은 파일이 Windows에서 어느 프로그램으로 열리는지 확인하지 못했습니다. 형식과 확장자를 바르게 보내는 것까지만 확인했습니다.
- 나스카 복호화는 시험하지 않았습니다.

확인한 것은 이렇습니다. 같은 폴더 배치(`app` 과 `data` 가 나란히)로 Production 모드를 띄워,
설치 화면 → 비밀번호 등록 → 설치 화면 닫힘(404) → 나가기 → **비밀번호만으로 다시 들어가기** 까지
한 번에 통과하는 것을 보았습니다. 자동 시험 80건도 모두 통과합니다.

처음 설치할 때는 **파트원에게 알리기 전에** 혼자 한 번 끝까지 해 보시길 권합니다.
막히면 `data\startup-error.log` 와 화면에 나온 문장을 그대로 보내 주세요.

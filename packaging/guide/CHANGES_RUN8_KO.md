# run7·run8 변경 설명

설치 순서와 데이터 위치는 바뀌지 않았습니다. 화면과 첨부 열기만 바뀌었습니다.

## run7

- 색, 간격, 모서리, 그림자를 CSS 변수로 두었습니다. 라이트·다크·시스템은 그 브라우저에만 저장되고, 첫 화면이 깜빡이지 않도록 스타일보다 먼저 적용됩니다.
- 글꼴은 설치되어 있으면 Pretendard, 없으면 맑은 고딕과 Segoe UI입니다. 폰트 파일을 넣지 않았고 외부 주소도 쓰지 않습니다.
- 건 상세에서 남아 있는 자료를 누르면 PDF·이미지·텍스트는 창 안에서 보고, 그 외와 HTML·SVG는 내려받기만 합니다. 서버는 파일을 실행하지 않습니다. 응답에는 `Content-Disposition`, `nosniff`, 스크립트를 막는 CSP를 붙입니다. 열람은 이력에 남습니다. 나스카 암호문은 풀지 않습니다.

## run8

- 한글은 단어 중간에서 끊기지 않습니다. 짧은 표 칸은 한 줄로 두고, 긴 경로만 말줄임하거나 아무 곳에서나 줄바꿈합니다. 메뉴의 자간은 0입니다.
- 선택 상자, 체크 상자, 파일 선택은 브라우저 기본 모양 대신 이 화면의 높이와 색을 따릅니다. 파일은 끌어다 놓거나 키보드로 고릅니다.
- 건 목록 필터는 검색창과 조건이 한 줄 도구막대에 모이고, 적용된 조건은 칩으로 뺍니다.
- 상태는 색 점이 있는 배지입니다. 제목은 굵은 글씨이고 마우스를 올리면 밑줄이 생깁니다.
- 자료는 표 대신 파일 행입니다. 형식 색, 이름, 크기·등록자·등록일, 미리보기 또는 내려받기, 삭제 메뉴가 있습니다. 긴 경로는 말줄임과 복사입니다.
- 미리보기 창은 흐린 배경과 그림자가 있고, 파일 이름과 내려받기·닫기가 있습니다. Esc와 배경 클릭으로 닫힙니다.
- 넓은 화면은 왼쪽 메뉴입니다. 로고, 메뉴 아이콘, 아래쪽 사용자 카드, 테마 아이콘이 있습니다. 좁은 화면은 위쪽 막대와 접히는 메뉴입니다. 본문 위에 현재 위치가 있습니다.
- 할 일 숫자는 의미 색이 있고, 누르면 해당 목록으로 갑니다.

역할, 보존, 보류, 삭제 작업, 무결성 잠금, 백업 매니페스트, 원장, CSRF는 그대로입니다.

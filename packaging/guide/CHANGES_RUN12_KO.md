# 이번 판에서 바뀐 것

## 1. 콘솔에 쉬지 않고 올라오던 경고

요청이 올 때마다 아래 경고가 한 줄씩 올라왔습니다.

```
warn: Microsoft.AspNetCore.Antiforgery.DefaultAntiforgery[8]
      The 'Cache-Control' and 'Pragma' headers have been overridden ...
```

이 프로그램은 모든 응답에 `Cache-Control: no-store` 를 스스로 답니다. 위조 방지 토큰 기능은
그때마다 "헤더를 덮어썼다"고 알리는데, 우리가 이미 바라는 값으로 달아 둔 것이라 알릴 내용이
없습니다. 화면을 한 줄씩 채워 운영 감시를 가리므로 이 기능의 경고는 끄고 오류만 남깁니다.

`Program.cs` 와 `appsettings.json` 양쪽에 두었습니다. 설치 스크립트가 만드는 설정에도 들어갑니다.

## 2. 건 목록의 '최근 본 건' 칩

건 상세를 열면 그 건을 브라우저에 적어 두었다가, 건 목록 위에 칩으로 다시 보여 주었습니다.
그런데 그 칩이 필터 칩과 똑같이 생겨 섞여 보였고, `모두 지우기` 는 필터만 지우므로
최근 칩은 그대로 남았습니다. 그래서 `모두 지우기` 가 먹히지 않는 것처럼 보였습니다.

그 기능을 없앴습니다. 브라우저에 남아 있던 값도 치웁니다.
`모두 지우기` 는 이제 지울 필터가 있을 때만 보입니다.

## 3. 설치 꾸러미가 파일 하나

더 이상 조각으로 나누지 않습니다. `감사기록-설치.zip` 하나만 가져가면 됩니다.
`copy /b` 로 합치는 단계가 사라졌습니다.

## 4. zip 안의 한글 이름

이전 꾸러미는 한글 파일 이름에 "이건 UTF-8 이다" 라는 표시가 없었습니다.
한국어 Windows 의 압축 풀기는 그런 이름을 CP949 로 읽어 폴더 이름이 깨질 수 있습니다.
이번 판은 그 표시를 넣었습니다. 448개 이름 전부 확인했습니다.

## 하지 않은 것

- 이 꾸러미를 Windows 에서 실행하지 않았습니다.
- 다른 PC 브라우저에서 접속해 보지 않았습니다.
- 한국어 Windows 에서 압축을 풀어 폴더 이름을 눈으로 확인하지 않았습니다.
  zip 안의 표시가 규격에 맞는지만 확인했습니다.

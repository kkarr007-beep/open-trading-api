# run9 변경 설명

설치 순서는 바뀌지 않았습니다. 화면 폭, 저장 알림, 문서번호, 위쪽 메뉴, 자료 찾기, 징계기록, 설정 화면이 추가되었습니다.

## 화면

- 왼쪽 세로 메뉴를 없애고 위쪽 가로 메뉴로 바꿨습니다. 할 일, 건 목록, 자료, 징계기록, 관리, 설정이 있습니다. 좁은 화면에서는 메뉴가 접힙니다.
- 본문은 1280~1920px에서 화면 폭을 쓰고, 좌우 여백은 화면 크기에 따라 16px에서 40px 사이입니다. 그보다 훨씬 넓을 때만 1920px에서 멈춥니다.
- 저장, 자료 추가, 연한 저장처럼 내용을 바꾸는 동작은 그 자리에서 처리합니다. 누르는 동안 버튼에 '저장 중…'이 나오고, 결과는 화면 아래 알림으로 보입니다. 성공은 잠시 뒤 사라지고, 오류는 닫을 때까지 남습니다. 스크롤은 그대로입니다. 자바스크립트가 꺼져 있으면 예전처럼 저장 후 위쪽 안내로 돌아갑니다.

## 문서번호

- 새 건의 문서번호는 `연도-구분코드-순번`입니다. 2026년 업무진단 첫 건은 2026-01-01, 다음은 2026-01-02, 준법감사 첫 건은 2026-02-01입니다.
- 기본 코드는 업무진단 01, 준법감사 02입니다. 이미 번호를 발급한 코드는 관리자도 바꿀 수 없습니다.
- 번호는 등록하는 순간에 하나씩만 나갑니다. 같은 순간에 여러 건을 등록해도 번호가 겹치지 않습니다. 없어진 번호는 다시 쓰지 않습니다.
- 이미 저장되어 있는 문서번호는 바꾸지 않습니다. 비어 있는 예전 번호도 소급해서 채우지 않습니다.

## 자료와 설정

- 자료 화면에서 파일명, 형식, 등록자, 소속 건으로 찾고 미리보기로 열 수 있습니다. 건 목록 검색에도 파일명이 포함됩니다.
- 설정 화면에는 저장 방식, 구성 그림, 데이터 요약, 역할별 사용 방법이 있습니다. 서버 폴더 경로는 관리자에게만 보입니다.
- 건 목록 CSV, 인쇄용 페이지, 최근 본 건, 첨부 파일 SHA-256 확인을 넣었습니다.

## 징계기록

- 징계기록은 감사 건과 따로 둡니다. 누가, 언제, 어디서, 무엇을, 어떻게, 왜를 적고 처분과 관련 건을 붙입니다.
- 파트장과 관리자만 봅니다. 담당의 일상 화면과 처분 정보를 나누기 위해서입니다.
- 목록에서는 이름을 일부만 보여 줍니다. 상세를 열면 전체 이름이 보이고 열람 이력이 남습니다.
- CSV는 관리자만 받을 수 있고 이력에 남습니다. 보존 만료와 삭제 보류는 감사 건과 같은 취지로 동작합니다.
- 예시 이름은 가상갑, 가상을, 가상병입니다.

역할, 보존, 보류, 삭제 작업, 무결성 잠금, 백업 매니페스트, 원장, CSRF는 그대로입니다.

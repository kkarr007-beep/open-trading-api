# 감사기록 운영 안내

이 프로그램은 인터넷이 없는 Windows x64 감사 서버 한 대에서 돕니다. 다른 컴퓨터는 브라우저만 사용합니다. 이 안내를 만든 환경은 Linux에서 교차 게시와 자동 시험을 한 것이고, Windows 서비스 설치, 내부망 접속, 나스카로 암호화된 파일을 여는 시험은 하지 않았습니다.

## 1. 폴더

```text
감사기록\
  app\       프로그램. 서비스 계정은 읽기·실행
  data\      audit.db 하나. 서비스 계정만 수정. 공유 금지
  files\     암호문 바이트. 서비스 계정만 쓰기·삭제
  backup\    이 프로그램이 만든 내부 복사본
  config\    설정 예시
  scripts\   설치·시작·제거
```

`data`와 `backup`은 SMB로 열지 않습니다. `files`만, 감사파트 그룹에 읽기 전용 공유를 줄 수 있습니다. 서버는 나스카 복호화 대상으로 등록하지 않습니다.

이 위치의 파일은 사용자 컴퓨터의 나스카로 연다.

사용자는 화면에 적힌 UNC 경로를 자기 Windows PC에서 엽니다. 열림 여부는 나스카가 판단합니다. 프로그램은 내용을 읽지 않고, 미리보기·PDF·본문 검색·내용 해시를 하지 않습니다.

## 2. 계정

역할은 담당, 파트장, 관리자입니다. 셋 다 모든 건을 봅니다.

- 담당은 초안, 조치요구, 회신, 이행 기록, 자료 추가를 할 수 있습니다. 확정, 확정 취소, 종결, 보류, 연한 전 파일 삭제는 할 수 없습니다.
- 파트장은 확정, 확정 취소, 종결, 확정 후 연한 변경을 할 수 있습니다. 연한 변경과 확정 취소는 사유가 필요합니다.
- 관리자는 파트장의 권한에 계정, 백업, 삭제 보류, 연한 전 파일 삭제를 더합니다.
- 한 번이라도 확정된 건은 확정을 취소해도 담당의 연한 변경·첨부 빼기가 돌아오지 않습니다.
- 마지막 활성 관리자는 끄거나 내릴 수 없습니다.
- 비밀번호는 ASP.NET Core PasswordHasher로 저장합니다. 초기화·변경·끄기는 그 계정의 기존 세션을 끊습니다.
- 운영 모드에는 알려진 비밀번호의 예시 계정을 넣지 않습니다. 예시 모드는 개발 확인용이며 운영 자료와 섞지 않습니다.

## 3. 보존

기산일은 최초 결과 확정일입니다. 취소와 재확정은 그 날짜를 바꾸지 않고, 나중 확정은 이력에만 남습니다. 연한은 양수여야 확정할 수 있습니다.

만료 시각은 최초 확정일에 보존연한(달력 연)을 더한 날의 00:00(한국 표준시)입니다. 2월 29일이 없는 해는 그달 말일로 맞춥니다. 예: 2024-02-29에 1년이면 2025-02-28 00:00 KST입니다. 이 규칙은 프로그램이 고른 계산이며 회사나 법령이 정한 연한이 아닙니다. 연한 숫자는 건마다 입력합니다.

만료되면 결과 본문, 조치 내용, 회신 본문, 확인 본문, 파일과 저장 위치를 지웁니다. 목록, 결과 한 줄, 조치의 제목·유형·대상·날짜·상태, 자료 이름과 삭제일, 이력 전체는 남습니다. 휴지통으로 보내지 않습니다. 하나라도 남으면 자료삭제됨으로 표시하지 않고 재시도합니다. 삭제 보류 중에는 수동·자동 삭제 모두 건너뜁니다. 보류를 풀면 원래 만료일을 유지한 채 다음 처리에서 지웁니다. 서버가 꺼져 있던 만료분은 다시 켤 때 처리하고, 이력의 시각은 실제 처리 시각입니다.

이미 지운 파일과 본문은 확정 취소, 재확정, 연한 연장, 보류로 되살리지 않습니다.

SQLite `secure_delete`, 체크포인트, VACUUM은 논리적인 잔여를 줄입니다. SSD 웨어 레벨링, 볼륨 섀도 복사, 예전 백업에 남은 바이트까지 지워졌다고 말하지 않습니다.

운영 모드에서는 관리자가 관리 화면에서 이 기준을 확인하기 전에는 자동 삭제를 실행하지 않습니다.

## 4. 백업

관리자만, 허용된 내부 디스크 아래에서 수동으로 실행합니다. SQLite Backup API로 데이터베이스를 맞춘 뒤 그 스냅샷이 가리키는 파일만 바이트로 복사합니다. 내용을 해석하지 않습니다. 인터넷 백업은 없습니다.

이 프로그램이 만든 완료 백업의 기본 정리 기준은 최대 7일과 최대 7세대입니다. 바꿀 수 있고, 회사 규정이나 법정 기간이 아닙니다. 매니페스트로 이 앱이 만들었음이 확인되는 폴더만 지웁니다. 다른 백업, 다른 폴더, 사용자가 둔 파일은 건드리지 않습니다.

한 번에 덮어쓰는 복구 버튼은 없습니다. 오래된 백업을 되돌리면 그 사이에 지운 자료가 다시 보일 수 있습니다.

복구가 필요하면:

1. 서비스를 멈춥니다.
2. 현재 `data\retention-ledger.log`는 그대로 둡니다. 백업 안의 `ledger-copy.log`로 덮어쓰지 않습니다.
3. 데이터베이스와 `files`만 백업 시점으로 되돌립니다.
4. 서비스를 켭니다. 원장의 삭제와 데이터베이스가 다르면 `RESTORE-LOCK` 파일이 없어도 읽기 전용으로 잠기고, 본문과 자료 위치는 숨깁니다. 삭제는 자동으로 다시 적용하지 않습니다.
5. 관리자가 관리 화면에서 “삭제 기록 다시 적용”을 누릅니다. 그 실행만 이력에 남고, 적용이 끝난 뒤에 일반 사용이 열립니다. 원장이 없거나 파일 삭제가 끝나지 않으면 읽기 전용으로 남습니다.

원장마저 오래된 복사본뿐이면 이후의 조기 삭제를 다시 증명할 수 없습니다. 그 상태에서는 잠금을 지우지 않습니다.

## 5. 이력

이력은 추가만 합니다. 각 줄은 자기 필드와 앞줄 지문을 넣은 SHA-256입니다. 첫 줄, 중간 줄, 마지막 줄, 하나만 있는 줄의 내용 수정은 화면 위 이력 훼손으로 나타납니다. 훼손 중에는 변경이 막히고, 그 화면을 정상 증거로 보면 안 됩니다.

탐지하지 못하는 경우: 꼬리만 지우고 저장된 꼬리 값까지 맞추는 경우, 체인 전체를 다시 계산하는 경우, 데이터베이스 파일을 통째로 바꾸는 경우. 외부 공증은 없습니다.

## 6. Windows 서비스와 권한

처음 관리자는 서버의 `http://127.0.0.1:47321/account/setup` 에서만 만듭니다. 다른 주소의 첫 관리자 만들기는 거부됩니다. 관리자를 만든 뒤에 내부망 주소를 엽니다.

설정은 `app\appsettings.json` 과 `app\appsettings.Production.json` 만 읽습니다. `config\` 의 예시를 그 이름으로 복사해야 적용됩니다. 키 목록, 주소 우선순위, 서비스 시작·중지·제거, 인증서 암호 파일, icacls와 방화벽 예시는 `guide\INSTALL_KO.md` 에 있습니다.

`sc.exe create` 는 계정 암호를 물어보지 않습니다. 암호를 명령줄에 적는 방식은 쓰지 않습니다. `scripts\service.ps1 -Action install` 이 자격 증명을 서비스 제어 관리자에 넘기고, 암호는 출력하지 않습니다. 이 명령은 Windows에서 실행하지 않았습니다.

서비스 계정은 대화형 로그온이 없는 전용 계정입니다. LocalSystem은 쓰지 않습니다.

- `app`: 서비스 읽기·실행, 관리자 전체
- `app-keys`: 데이터 보호 키와 인증서 암호 파일. 서비스만
- `data`, `backup`: 서비스 수정. SMB 공유 안 함
- `files`: 서비스 수정. 감사파트 그룹은 읽기 전용 SMB만

운영 접속은 내부 CA가 발급한 인증서를 씁니다. `Audit:CertificatePath`에 PFX를 둡니다. 암호는 `AUDIT_CERT_PASSWORD` 또는 `AUDIT_CERT_PASSWORD_FILE` 만 사용하고 설정 파일에 적지 않습니다. 루프백이 아닌 HTTP는 `AllowInsecureHttp`를 명시하기 전에는 시작하지 않습니다.

수신 주소는 `--urls`, 그다음 `AUDIT_URLS`, 그다음 `Audit:Urls`, 없으면 `http://127.0.0.1:47321` 입니다. 인증서 경로가 있으면 `BindAddress`와 `Port`(기본 127.0.0.1:8443)로 HTTPS를 듣습니다.

## 7. 확인하지 않은 것

- 이 패키지의 Windows 실행, 서비스 등록, 재부팅
- 다른 PC의 브라우저 접속, 방화벽, 내부 CA
- 암호화된 파일을 담당자 PC의 나스카로 여는 시험
- 맑은 고딕이 없는 Linux에서의 글꼴 대체는 시스템 기본 글꼴이며, Windows에서는 `Malgun Gothic`만 지정합니다

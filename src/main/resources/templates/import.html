백업 옮겨 오기

예전 프로그램의 백업 파일

여러 파일을 한 번에 넣을 수 있습니다. 파일마다 내용을 보고 알아서 나눠 넣습니다.

  • 업무 일정 · 예전 '업무·일정 관리'(v2와 그 이전 판)에서 설정 · 데이터 → JSON 내보내기로 받은 파일, 또는 이 프로그램의 업무 설정에서 내려받은 파일
  • 사규 · 예전 '사규 관리 시스템'(v4와 v3)에서 설정·백업 → JSON 백업으로 받은 파일, 또는 이 프로그램의 사규 설정에서 내려받은 파일
  • 감사 건·징계기록 · 서버판 감사기록은 관리 화면의 '이전 판에서 옮겨 오기'로 가져옵니다.

JSON 백업 파일을 고르거나 끌어 놓으세요 (여러 개 가능)

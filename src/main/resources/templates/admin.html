관리

백업, 보존 만료 처리, 이력 점검, 문서번호 구분코드, 이전 판 데이터 가져오기.

백업

데이터 파일과 files 폴더를 이 컴퓨터나 연결된 디스크의 폴더로 복사합니다. 인터넷으로 보내지 않습니다. 백업에는 원문과 읽어 둔 내용이 모두 들어 있으니 보관 위치에 유의하세요.

시각상태위치비고

보존 만료 처리

최초 확정일에 보존연한을 더한 날이 지난 건의 결과 본문, 조치 내용, 회신·확인 본문, 파일, 읽어 둔 내용을 지웁니다. 목록 정보, 결과 한 줄, 이력은 남습니다. 삭제 보류 중인 건은 건너뜁니다. 지운 것은 되돌릴 수 없습니다.

삭제 임박·만료 건 보기 자동 삭제 설정

이력 점검

이력의 각 줄은 앞줄의 지문(SHA-256)을 가집니다. 데이터 파일을 직접 고치면 여기서 드러납니다. 꼬리와 기준값을 함께 바꾸거나 전체를 다시 계산한 경우는 알아내지 못합니다.

문서번호 구분코드

문서번호는 연도-구분코드-일련번호로 자동 부여합니다. 이미 번호를 발급한 구분코드는 바꿀 수 없습니다.

이전 판 데이터 가져오기

서버판(C#)의 '감사기록' 폴더를 적으면 그 안의 건, 조치, 자료, 징계기록, 이력을 옮겨 옵니다. 이 프로그램에 건과 징계기록이 하나도 없을 때만 할 수 있고, 원래 폴더는 읽기만 합니다.

데이터 위치

data(데이터 파일), files(자료 원문), inbox(수집함), backup(백업) 폴더가 이 아래에 있습니다. 데이터 파일을 직접 열어 고치지 마세요.

프로그램 끝내기

전용 창으로 쓰는 경우에는 창을 닫으면 프로그램도 끝납니다. 브라우저로 열어 쓰는 경우에는 여기서 끝냅니다.

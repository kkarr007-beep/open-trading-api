외부조사 법인 유착 혐의 1차 분석
==================================================

파이썬 설치가 필요 없습니다. 실행 파일 하나로 동작합니다.


[ 먼저 해볼 것 ]

"유착분석.exe" 를 두 번 누르고 물음에 답해 보세요.
실제 데이터 없이도 프로그램이 도는지 확인하려면
아무 CSV나 넣지 말고 먼저 담당자에게 시험용 파일을 요청하세요.


[ 쓰는 방법 ]

방법 1. 끌어다 놓기
  분석할 CSV 파일을 "유착분석.exe" 위에 끌어다 놓습니다.

방법 2. 두 번 누르기
  "유착분석.exe" 를 두 번 누르면 창이 열립니다.
  - 분석할 파일: 경로를 적거나 파일을 창 안으로 끌어다 놓습니다
  - 시트가 나뉘어 있으면 한 줄에 하나씩 넣고 마지막에 빈 줄
  - 기준년: 그냥 Enter 를 누르면 전체 기간
  - 결과 폴더: 그냥 Enter 를 누르면 원본 옆에 "분석결과" 폴더 생성


[ 처음 실행할 때 ]

- 창이 뜨기까지 10~20초 걸립니다. 내부에서 압축을 푸는 시간입니다.
- 백신이 경고를 띄울 수 있습니다. 이런 방식으로 묶은 파일에서 흔한 일입니다.
  차단되면 전산 담당자에게 예외 등록을 요청하세요.


[ 원본 데이터 준비 ]

SQL에서 내려받은 엑셀을 "다른 이름으로 저장" -> CSV 형식으로 저장합니다.
10만 건 기준 1~3분 정도 걸립니다.


[ 결과 읽는 순서 ]

1. 엑셀 "00_요약" 시트에서 데이터가 제대로 들어갔는지 확인
2. "99_컬럼점검" 시트에서 비어 있는 컬럼이 없는지 확인
3. HTML 보고서로 전체 그림 파악
4. 순위 시트에서 대상 선정
5. "90_소명대상건" 시트로 건별 목록 확보


[ 해석 시 주의 ]

혐의도는 동료 집단 대비 통계적 이상 신호를 점수화한 값입니다.
그 자체가 비위 사실을 뜻하지 않습니다. 담당 구역이나 사건 구성에
정당한 사유가 있을 수 있으므로 소명 절차로 확인해야 합니다.


[ 오류가 났을 때 ]

창에 나온 내용을 그대로 복사해 담당자에게 전달하세요.
창이 바로 닫히면 명령창에서 실행해 화면을 남길 수 있습니다.

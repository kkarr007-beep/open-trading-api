외부조사 법인 유착 혐의 1차 분석
==================================================

파이썬 설치가 필요 없습니다. 실행 파일 하나로 동작합니다.


[ 실행 준비 전 ]

"유착분석.exe" 를 두 번 눌러 화면이 뜨는지 확인합니다.
보안 소프트웨어가 차단할 수 있으므로,
아무 CSV로 먼저 돌려 보고 막히면 전산 담당자에게 허용을 요청하세요.


[ 실행 방법 ]

방법 1. GUI 실행 (기본)
  "유착분석.exe" 를 두 번 누르면 창이 열립니다.
  - 엑셀에서 데이터를 선택(머리글 포함)하고 Ctrl+C 로 복사합니다.
  - "엑셀 데이터 붙여넣기" 버튼을 누릅니다.
  - 기준년, 조직계층, 결과 폴더를 설정한 뒤 "분석 시작"을 누릅니다.

방법 2. 파일 끌어다 놓기
  분석할 CSV 파일을 "유착분석.exe" 위에 끌어다 놓습니다.

방법 3. 콘솔 실행
  명령 프롬프트에서: 유착분석.exe --console
  파일을 직접 지정하거나 경로를 입력하는 대화형 방식입니다.


[ 보안 환경에서 파일 읽기가 막히는 경우 ]

CSV 파일 읽기가 보안 정책으로 막히면 방법 1(붙여넣기)을 쓰세요.
엑셀에서 Ctrl+A → Ctrl+C 로 전체를 복사한 뒤 붙여넣기 버튼을 누르면 됩니다.


[ 머리글이 다를 때 ]

머리글 표기가 조금 달라도 자동으로 알아봅니다.
("보상담당자명", "손사법인명", "사고일자" 처럼 달라도 됩니다)

확신이 서지 않는 항목이 있으면 "컬럼 매핑 확인" 창이 뜹니다.
  - 빨간 항목: 반드시 지정해야 합니다 (청구번호, 담당자, 손사법인)
  - 노란 항목: 자동으로 붙였으나 맞는지 확인이 필요합니다
  - 오른쪽에 보이는 예시 값으로 맞는 컬럼인지 확인하세요

매핑을 다시 보려면 데이터 탭의 "컬럼 매핑" 버튼을 누릅니다.


[ 처리 시간과 장애 ]

- 창이 뜨기까지 10~20초 걸립니다. 내부에서 압축을 푸는 시간입니다.
- 보안 소프트웨어가 막을 수 있습니다. 이런 경우에는 보안 설정에서 허용 처리 합니다.
  차단되면 전산 담당자에게 예외 허용을 요청하세요.


[ 분석용 데이터 준비 ]

SQL에서 내려받은 데이터를 "다른 이름으로 저장" → CSV 형식으로 저장합니다.
10만 행 기준 1~3분 정도 걸립니다.
파일 읽기가 막히면 엑셀에서 전체 복사 → 붙여넣기로 입력합니다.


[ 결과 읽는 순서 ]

1. HTML 보고서를 열고 맨 위 "읽는 법"을 먼저 봅니다.
   혐의도와 등급이 무엇을 잰 수치인지 설명합니다.
2. "혐의 순위"에서 확인할 대상을 고릅니다.
3. "인물별 상세"에서 이름을 고르면 그 사람의 지표별 점수와 근거,
   위임 업체 전체 내역이 나옵니다.
4. 엑셀 "99_컬럼점검" 시트에서 빈 값 있는 컬럼의 영향을 확인합니다.
5. 엑셀 "90_소명대상건" 시트에서 건별 목록을 뽑아 소명을 요청합니다.

전 직원 위임 내역은 엑셀 "14_담당자별업체",
팀장·부서장 내역은 "15_차상위자별업체" 시트에 있습니다.


[ 보고서로 출력하기 ]

HTML 보고서 위쪽의 "인쇄 / PDF 저장" 버튼을 누릅니다.
A4 기준으로 맞춰져 있고, 인쇄물에는 선택 상자와 버튼이 나오지 않습니다.
"인물별 상세"는 그때 선택돼 있는 사람만 인쇄됩니다.


[ 해석 시 주의 ]

혐의도는 통계 검정 결과 동료에 비해 이상 신호가 강한 순서를 수치화한 것입니다.
그 자체로 위반 여부를 판정하지 않습니다. 같은 점수여도 업무 특성이나
사정이 다를 수 있으므로 소명 과정을 확인해야 합니다.


[ 오류가 날 때 ]

창에 나온 내용을 그대로 복사해 담당자에게 전달하세요.
창이 바로 닫히면 명령창에서 실행해 화면을 남길 수 있습니다.

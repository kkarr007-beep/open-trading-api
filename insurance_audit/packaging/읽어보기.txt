외부조사 법인 유착 혐의 1차 분석 프로그램
==================================================

[ 설치 방법 ]

1. 이 폴더를 통째로 내부망 PC에 옮깁니다.
   (바탕화면이나 D 드라이브 등 쓰기 가능한 곳)

2. "설치.bat" 파일을 두 번 누릅니다.
   - 파이썬을 자동으로 찾아 필요한 것을 설치합니다.
   - 설치가 끝나면 가짜 데이터로 동작 확인까지 자동으로 합니다.
   - 검증 폴더에 HTML 파일이 생기면 정상입니다.

3. 실제 데이터를 분석할 때는
   CSV 파일을 "분석실행.bat" 위에 끌어다 놓습니다.
   결과 폴더에 엑셀과 HTML 보고서가 생깁니다.


[ 파이썬이 없다고 나오는 경우 ]

전산 담당자에게 아래 내용으로 요청하세요.

  - 파이썬 3.9 이상 64비트 설치
  - 설치할 때 "Add Python to PATH" 항목 선택
  - 설치 후 pip 사용 가능하도록 설정

파이썬만 깔리면 나머지는 이 폴더 안의 파일로 전부 설치됩니다.
외부 인터넷 연결은 필요하지 않습니다.


[ 원본 데이터 준비 ]

SQL에서 내려받은 엑셀을 "다른 이름으로 저장" -> CSV 형식으로 저장합니다.
시트가 나뉘어 있으면 각각 CSV로 저장한 뒤 명령창에서 함께 넘깁니다.

  py -m insurance_audit.main --input 1분기.csv 2분기.csv --outdir 결과


[ 결과 읽는 순서 ]

1. 엑셀의 "00_요약" 시트에서 데이터가 제대로 들어갔는지 확인
2. "99_컬럼점검" 시트에서 비어 있는 컬럼이 없는지 확인
3. HTML 보고서로 전체 그림 파악
4. 엑셀의 순위 시트에서 대상 선정
5. "90_소명대상건" 시트로 건별 목록 확보

혐의도는 동료 집단 대비 통계적 이상 신호를 점수화한 값입니다.
그 자체가 비위 사실을 뜻하지 않으므로 소명 절차로 확인해야 합니다.

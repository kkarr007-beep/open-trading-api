# 외부조사 법인 유착 혐의 1차 발굴

보험금 심사에서 외부 손해사정법인으로 내보낸 조사 배당 데이터를 받아
보상담당자 · 차상위 결재자 · 손사법인 사이의 이상 신호를 찾아 순위를 매긴다.

## 실행

```bash
# 1차: CSV로 내보낸 파일을 바로 읽는다
python -m insurance_audit.main --input 조사배당.csv --outdir 결과

# 시트가 나뉘어 반출됐다면 여러 개를 넘긴다
python -m insurance_audit.main --input 1분기.csv 2분기.csv --outdir 결과

# 기준년을 골라서 본다
python -m insurance_audit.main --input 조사배당.csv --year 2024 2025

# 조직 계층을 지정한다 (생략하면 표본을 보고 정한다)
python -m insurance_audit.main --input 조사배당.csv --org-level 소속3

# 인코딩이 안 잡히면 직접 지정한다
python -m insurance_audit.main --input 조사배당.csv --encoding cp949
```

산출물은 두 개다.

- `유착분석_날짜.xlsx` — 주체별 순위, 현황 표, 지표별 근거, 소명 대상 건별 목록
- `유착분석_날짜.html` — 요약 대시보드와 도해. 외부 자원을 부르지 않아 내부망에서 그대로 열린다

## 엑셀 시트 구성

| 시트 | 내용 |
|---|---|
| `00_요약` | 데이터 규모, 지표별 산출 여부, 결과 개요 |
| `01~05_*순위` | 담당자 · 결재자 · 법인 · 소속 · 조합 혐의 순위 |
| `10_연도별업체순위` | 연도별 업체 위임건수 · 위임율 · 순위 · 전년 대비 증감 |
| `11_업체×연도위임율` | 업체를 행, 연도를 열로 둔 위임율 표 |
| `12_소속2별업체` `13_소속3별업체` | 조직 계층별 업체 구성비와 조직 내 순위 |
| `14_담당자별업체` | 담당자별 업체 구성비 |
| `20~29_*` | 지표 A~J의 산출 근거 |
| `90_소명대상건` | 상위 혐의 담당자의 건별 목록 |
| `99_컬럼점검` | 컬럼별 채움률. 적재가 제대로 됐는지 먼저 본다 |

## 필요 환경

`pandas`, `numpy`, `openpyxl`. `scipy`는 있으면 쓰고 없으면 정규근사로 갈음한다.
차트 라이브러리나 그래프 패키지는 쓰지 않는다. 내부망에서 설치가 막히는 경우를
고려해 의존성을 최소로 뒀다.

## 먼저 검증하고 쓴다

실제 데이터를 넣기 전에 합성 데이터로 탐지기가 반응하는지 확인한다.
유착 패턴 8종을 일부러 심어 둔 가짜 데이터를 만들어 돌려 보면 된다.

```bash
python -m insurance_audit.make_sample --rows 40000 --out 샘플.csv
python -m insurance_audit.main --input 샘플.csv --outdir 검증
```

심어 둔 대상이 순위 상단에 올라오면 정상이다. 대조표는 실행 시 화면에 출력된다.

## 분석 단위

반출 표는 한 청구건이 담보별 · 지급처별로 여러 행에 나뉘어 있다. 행을 그대로
세면 조사 건수가 아니라 지급 건수가 잡히고, 배당 편중을 집계하면 지급처가 많은
사고가 상위로 올라올 뿐 유착 신호는 묻힌다. 그래서 두 단위를 나눠 쓴다.

| 단위 | 정의 | 쓰는 곳 |
|---|---|---|
| 지급 단위 | 원본 행 그대로 | 지급처 · 예금주 분석, Benford |
| 배당 단위 | 청구번호 × 손사법인 | 배당 편중, 결과 편향, 금액 비교 등 나머지 전부 |

## 지표

| 지표 | 보는 것 | 방법 |
|---|---|---|
| A 배당편중 | 담당자가 특정 법인에 몰아줬는지 | 같은 점포 동료 배당률을 기대치로 이항검정 |
| B 결과편향 | 법인별 조사결과 쏠림 | 담보 · 사고원인 층화 후 표준화 잔차 |
| C 금액이상 | 유사건 대비 지급액 과다 | 층별 순위합 검정(Stouffer) + Benford 첫자리 |
| D 결재라인 | 결재 라인 고착과 즉시결재 | 3자 조합 편중 + 당일결재 비율 이항검정 |
| E 조사자편중 | 법인 안에서 특정 조사자 고정 | 점포 기준과 법인 내 기준 두 갈래 이항검정 |
| F 지급처이상 | 제3자 예금주 반복 수령 | 서로 다른 피보험자 수, 동일금액 반복, 담당자 편중 |
| G 구상포기 | 구상 가능한데 포기했는지 | 사고원인 층화 후 구상률 잔차 |
| H 처리속도 | 조사가 형식에 그쳤는지 | 담보 층화 후 처리일수 순위합 검정 |
| I 인물이동 | 소속을 옮겨도 같은 업체로 보내는지 | 소속마다 그 소속 동료 기준으로 따로 검정 |
| J 조직전환 | 지점 주력 업체가 통째로 바뀌었는지 | 연도 간 점유율 두 비율 검정 + 결재자 교체 대조 |

I와 J가 이번에 더해진 지표다. 둘은 서로 보완한다.

- **I 인물이동**은 업체 선호가 조직이 아니라 사람을 따라다니는 경우를 잡는다.
  한 지점에서만 몰리는 것은 그 지점의 거래 관행일 수 있지만, 발령을 받아 옮긴
  뒤에도 같은 업체 편중이 남으면 지점 관행으로는 설명되지 않는다. 각 소속의
  기준은 그 소속 동료들에게서 따로 뽑고, 가장 약한 소속에서의 강도를 대표값으로
  쓴다. 어느 지점에서든 유지됐다는 뜻이 되기 때문이다.
- **J 조직전환**은 반대로 사람이 아니라 조직 단위로 위임처가 갈아치워지는 경우를
  잡는다. 연도 간 점유율 변동이 큰 구간을 찾고, 그 시점에 결재자가 바뀌었는지,
  담당자 구성은 그대로였는지를 붙인다. 담당자가 그대로인데 결재자만 바뀌면서
  위임처가 옮겨갔다면 그 자체가 소명 대상이다.

두 가지 원칙을 지킨다.

1. **기대값 대비 편차로 본다.** 단순 건수 1위는 업무량이 많다는 뜻일 뿐이다.
   기대치를 낼 때는 본인 건을 빼고 계산한다. 본인 물량이 커서 기대치를 끌어올리면
   편중이 정상으로 보이기 때문이다.
2. **비교 전에 층화한다.** 담보구분 · 사고원인 · 피해유형을 맞추지 않으면
   "그 법인은 원래 어려운 건만 받는다"는 반박에 결과가 무너진다.

## 혐의도 계산

각 지표의 검정 통계량을 유의도 기준으로 0~100에 편다. 하한(보통 p=0.01에
해당하는 값) 아래는 0으로 깔고, 충분히 강한 값에서 100으로 포화시킨다.
순위 백분위만 쓰면 차이가 없는 집단에서도 순위만으로 점수가 생겨
"기대 20%인데 22%"가 상위 점수를 받는다.

혐의도는 두 성분을 섞는다.

```
혐의도 = 0.6 × 가중합 + 0.4 × 최고지표
```

가중합은 여러 지표에 걸쳐 고르게 이상한 경우를, 최고지표는 한 지표에서
극단적으로 튀는 경우를 잡는다. 가중합만 쓰면 단일 지표 극단값이 가중치 몫에
눌려 순위에서 밀린다.

## 조정

`config.py` 한 곳에 모아 뒀다. 자주 손보게 되는 값은 다음과 같다.

- `MIN_CASES_*` — 표본 부족 대상을 순위에서 빼는 기준. 낮추면 대상이 늘지만 잡음도 는다
- `METRIC_WEIGHTS` — 지표 가중치
- `RISK_RULES` — 등급 구간
- `STRATA_*` — 층화 기준 컬럼
- `COLUMN_ALIASES` — 머리글 표기가 다를 때 여기에 추가한다
- `MIN_CASES_PER_POSTING` — 한 소속에서 이만큼은 처리해야 그곳 배당 성향으로 본다
- `MIN_SHARE_SHIFT` — 주력 업체가 바뀌었다고 볼 점유율 변동폭(%p)
- `CHART_*` — 도해에 담을 대상 수와 색을 따로 줄 업체 수

## 도해

차트 라이브러리를 쓰지 않고 SVG를 직접 그린다. 색은 색약 조건에서 인접 색이
구분되는지 검증한 순서를 고정으로 쓰고, 슬롯을 넘기면 꼬리를 "기타"로 접는다.
색을 더 만들어 쓰면 구분이 무너지기 때문이다. 모든 값은 숫자로도 함께 적어
색만으로 읽게 하지 않는다.

| 도해 | 형태 | 읽는 법 |
|---|---|---|
| 연도별 업체 위임율 | 히트맵 | 행을 가로로 읽으면 주력 업체 교체가 보인다 |
| 조직별 위임 구성 | 가로 누적 막대 | 한 색이 막대를 덮으면 거래처가 한 곳에 묶여 있다 |
| 담당자별 편중 | 막대 + 기준선 | 막대는 실제 비율, 세로선은 같은 점포 동료 기준 |
| 조직 위임처 전환 | 아령 도해 | 엷은 점이 전환 전, 진한 점이 전환 후 |

## 해석 주의

혐의도는 동료 집단 대비 통계적 이상 신호를 점수화한 값이다. 그 자체가 비위
사실을 뜻하지 않는다. 상위 대상의 업무 특성 · 담당 구역 · 사건 구성에
정당한 사유가 있을 수 있으므로, 소명 절차를 거쳐 확인해야 한다.
`90_소명대상건` 시트가 그 용도의 건별 목록이다.

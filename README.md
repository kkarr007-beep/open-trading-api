# 사내 도구 보관

사내 PC 에서 내려받아 쓰는 도구를 여기에 둡니다.
외부 통신을 하지 않으므로 내부망에서 그대로 쓸 수 있습니다.

## 사규 관리 시스템 v4

받는 방법 : 파일 이름을 누른 뒤 오른쪽 위 **Download raw file** 단추

| 받을 것 | 크기 | 쓰는 법 |
|---|---|---|
| [`sagyu-v4-setup.exe`](sagyu-v4-setup.exe) | 92MB |  **설치 파일.** 두 번 눌러 설치하면 시작 메뉴와 바탕 화면에 등록됩니다. 관리자 권한이 필요 없는 사용자 단위 설치입니다. |
| [`sagyu-v4-launcher.zip`](sagyu-v4-launcher.zip) | 66KB | **설치 없이.** 압축을 풀고 「사규관리 열기.bat」 을 누르면 주소창 없는 창으로 열립니다. |
| [`sagyu-v4.html`](sagyu-v4.html) | 194KB | **파일 하나만.** 두 번 누르면 브라우저에서 열립니다. 가장 간단합니다. |

### 설치 파일로 하실 때

- 서명이 없어 **Windows 에서 경고가 뜹니다.** 「추가 정보」 → 「실행」 을 누르면 진행됩니다.
  사내 정책으로 막혀 있으면 설치가 안 됩니다. 그때는 위의 다른 두 가지를 쓰십시오.
- 내려받은 파일이 맞는지 확인하시려면, 명령 프롬프트에서

  ```
  certutil -hashfile sagyu-v4-setup.exe SHA256
  ```

  값이 아래와 같아야 합니다.

  ```
  a22863633f3ea0dd26a00fb60733c73794feef8d43eeb9cd45ffefcfd82a5cbf
  ```

- 지울 때는 **설정 → 앱** 에서 「사규 관리 시스템」 을 제거하십시오.
  등록한 사규와 메모는 지워지지 않고 남습니다.

### 4.3.1 — 붙여넣기 바로잡음

4.3.0 에서 Word 문서를 붙여넣으면 **본문이 전부 「전문」으로 들어가고 부칙의 조가
갈라지지 않던 문제**를 고쳤습니다.

원인은 4.3.0 에서 새로 넣은 꾸밈 표시였습니다. Word 사규는 조 제목이 굵게 되어 있어
`**제1조(목적)**` 이 되는데, 조문 분석기는 `제` 로 시작하는 줄만 조로 보기 때문에
한 줄도 조로 잡히지 않았습니다.

- 조·장·부칙·별첨 **머리글에는 꾸밈 표시를 달지 않습니다.** 문단 전체가 굵은 경우도
  표시를 떼고, 줄 안의 일부만 굵은 경우에만 남깁니다.
- 구조 분석(조·항·호·목·표)은 **표시를 떼어낸 글로** 판정합니다.
- 그래도 조가 하나도 안 잡히면 표시를 전부 떼고 **다시 한 번 가릅니다.**
- 본문의 **들여쓰기가 저장될 때 잘리던 것**을 고쳤습니다.
- `1. 제5조(양정기준)의 …` 처럼 호 번호 뒤에 오는 인용이 **두 줄로 쪼개지던 것**을
  고쳤습니다.
- 본문 속 `제4조제1항` 같은 **인용은 새 조로 갈라지지 않고** 링크로만 잡힙니다(종전대로).

### 4.3.0 에서 바뀐 것

**Word·한글에서 복사한 서식이 그대로 들어옵니다.**
예전에는 글자만 뽑고 서식을 버려서 정렬이 무너졌습니다. 이제는 옮겨 담습니다.

| Word | 화면 |
|---|---|
| 들여쓰기(`margin-left`) | 단계별 들여쓰기 (줄이 넘어가도 자리에 맞춰 이어짐) |
| 가운데 · 오른쪽 정렬 | 그대로 |
| 굵게 · 밑줄 · 취소선 | 그대로 |
| 표 · 글머리 목록 | 그대로 |

평문으로 보관하므로 검색·신구 비교·백업·CSV 는 그대로 동작합니다.

- **붙여넣을 때 섞여 들어오던 CSS 코드를 걷어냅니다.** Word 가 같이 보내는
  스타일·주석 덩어리가 본문에 들어가던 문제입니다.
- **부칙이 여러 개**여도 각각 따로 묶입니다. `부칙<2012.11.01> 제1조` 처럼
  겹치지 않게 번호를 붙이고, 읽기 화면에서 부칙별 머리글로 갈라 보여줍니다.
- **별첨·별표·별지·붙임·서식**을 조 번호로 잡고 옆 내용을 제목으로 씁니다
  (`별첨1  징계양정기준표`).
- **조문 편집창을 크게** 했습니다(1180×880, 「넓게」 또는 F11 로 더 크게).
  글자 크기 조절(`－ ＋`, Ctrl+휠), 고정폭 글꼴, 자동 줄바꿈 끄기/켜기,
  줄·글자 수 표시, Ctrl+S 저장.
- **편집 중 엔터**를 치면 윗줄 들여쓰기가 이어집니다. 윗줄이 `①`·`1.`·`가.` 로
  시작하면 번호 너비만큼 더 들어가 글자가 세로로 맞습니다.
  **Tab / Shift+Tab** 으로 여러 줄을 한 번에 들이고 내보냅니다.
- **조문 삭제**를 넣었습니다(편집창 왼쪽 아래, 조문 옆 `⋯` 메뉴).
  지금 보는 버전에서만 빠지고 지난 버전에는 남습니다. 지우기 직전 스냅샷을 남깁니다.
- **편집창이 바깥을 눌러도 닫히지 않습니다.** 닫을 때 고친 내용이 있으면 되묻습니다.

### 4.2.0 에서 바뀐 것

- **개정판은 같은 사규 안으로.** 같은 이름으로 다시 등록하면 「개정 버전으로 추가」를
  고를 수 있습니다. 이미 둘로 나뉜 사규는 사규 본문 화면의 **「하나로 합치기」** 로
  합칩니다(버전은 시행일 순, 북마크·메모·컬렉션도 함께 옮깁니다).
- **개정 표시.** 읽기 화면의 「개정 표시」를 누르면 바로 앞 버전과 견주어
  **바뀐 곳이 빨갛게** 나옵니다. 신설·삭제된 조도 따로 표시합니다.
- **전체 목차**를 사규별로 정리하고, 사규명·조 번호·조 제목·본문으로 찾을 수 있게
  했습니다. **모두 펴기 / 모두 접기**도 넣었습니다.
- **조문에 그림**을 넣을 수 있습니다(조문 편집 → 그림 넣기). 폭 1200px 로 줄여
  파일 안에 함께 담습니다. 같은 자리에서 **표 틀 넣기**도 됩니다.
- **본문과 조문목록의 좌우를 바꾸고**(조문목록 머리의 단추) **가운데 선을 끌어
  너비를 조절**할 수 있습니다. 두 번 누르면 기본값, 화살표 키로도 됩니다.
- **감사점검 추출**을 카드로 바꾸고, 출처 조항이 줄바꿈으로 칸을 늘이지 않게
  한 줄로 고정했습니다. 전체 선택·추리기도 넣었습니다.
- **감사 보고서**를 요약 숫자 + 머리행 있는 표로 정리하고 좌우 여백을 잡았습니다.
- **엔터로 넣은 줄바꿈**이 카드 안에서 그대로 보입니다(시정조치·감사 이력·보고서 등).

### 4.1.0 에서 바뀐 것

- **표**를 표로 봅니다. Word·한글·엑셀·웹에서 표를 복사해 붙여넣거나
  `.docx` · `.hwpx` 파일을 열면 칸 구분을 살려 읽고, 조문에서도 표로 보여줍니다.
  백업(JSON·CSV)에도 칸 구분이 그대로 남아 다시 들여와도 표로 돌아옵니다.
- **읽기 본문을 카드형 · 목록형**으로 바꿔 볼 수 있습니다(본문 오른쪽 위).
  고르신 모양은 기억합니다.
- 본문과 조문목록 사이의 **빈 공간을 없앴습니다.**
- **하위 메뉴를 상단에 쭉 폈습니다.** 「더보기」를 누르면 감사·관리 메뉴까지
  윗줄에 모두 나옵니다. 창이 좁으면 예전처럼 펼침 메뉴로 바뀝니다.
- 설정의 **부서가 지워지지 않고 빈칸으로 남던 것**을 고쳤습니다.

### 화면 크기

처음 열면 **모니터에 꽉 차게** 뜹니다. 내용도 창 너비를 그대로 씁니다.

- 창 크기를 줄여 쓰시면 그 크기를 기억해 다음에도 그대로 엽니다.
- 다시 꽉 채우시려면 메뉴 **보기 → 화면에 꽉 채우기** (Ctrl+Shift+F)
- 글자가 작으면 **보기 → 확대** (Ctrl+`=`), 되돌리기는 **원래 크기** (Ctrl+0)
- 노트북에서 외부 모니터를 빼셔도 창이 화면 밖으로 나가지 않게 해두었습니다.

### 자료가 쌓이는 곳

**세 가지 방식은 자료를 각각 따로 보관합니다. 한 가지로 정해 쓰십시오.**

| 방식 | 자료가 쌓이는 곳 |
|---|---|
| 설치 파일 | `%APPDATA%\사규 관리 시스템` — 앱 메뉴의 **도움 → 자료가 쌓이는 곳 열기** 로 바로 열립니다 |
| launcher.zip | 압축을 푼 폴더 안의 `appdata` — 폴더째 옮기면 자료도 따라갑니다 |
| html 직접 열기 | 그 PC 의 브라우저 안 |

어느 방식이든 자료는 PC 안에만 있고 밖으로 나가지 않습니다.
설정 화면의 **JSON 백업**으로 내보내 두시면 방식을 바꾸셔도 옮길 수 있습니다.

# 감사기록

감사파트 전용 기록·기록물등재 프로그램입니다. Windows x64 서버 한 대에서 실행하고, 같은 내부망의 다른 컴퓨터는 브라우저로만 접속합니다. 실행 중 외부망 호출은 없습니다.

화면은 여섯 개입니다: 현황판, 할 일, 건 목록, 건 상세, 기록물 등록대장, 관리.

이 저장소의 기본 설정은 운영 모드입니다. 예시 데이터와 예시 계정은 `Audit:Mode`가 `Demo`일 때만 만들어집니다.

## 주요 기능

### 기록물등재

- **등록번호 자동 채번** — 건을 등록하면 `연도-일련번호`(예: `2026-001`)가 자동 부여됩니다. 번호는 등재 연도 기준으로 매겨지고 이후 바뀌지 않으며, 건의 연도를 고쳐도 다시 쓰지 않습니다. 부여 사실은 이력에 남습니다.
- **기록물 등록대장** — 전 건의 등록번호, 등재일, 결과확정일, 보존연한, 만료예정일, 상태, 자료 수를 대장 형식으로 봅니다. 연도·구분 필터, A4 인쇄 서식, Excel에서 바로 열리는 CSV 내려받기(UTF-8 BOM)를 제공합니다. 본문과 파일 내용은 대장과 CSV에 포함하지 않습니다.
- **보존연한 빠른 선택** — 1·3·5·10·30년 단추로 입력합니다. 연한 숫자는 건마다 입력하며 법정 보존연한이 아닙니다.
- **검색 확장** — 제목·대상·문서번호·철번호에 더해 등록번호와 결과 한 줄도 검색합니다. 목록 화면에서 `/` 키로 검색창에 바로 갑니다(입력 중에는 동작하지 않음).

### 현황판

전체·진행·기한초과·삭제예정 요약 카드, 연도별 등재 추이, 상태·구분 분포, 조치요구 진행 그래프, 최근 이력을 한 화면에서 봅니다. 그래프는 함께 제공되는 Chart.js로 그리며 외부 요청이 없습니다.

### 화면

- 사이드바 구조, 밝게·어둡게 모드(기기 설정을 따르고, 전환 값은 브라우저에만 저장), Pretendard 글꼴(서버가 함께 제공, 맑은 고딕 대체 포함), 상태 배지, 고정 표 머리글, 인쇄 서식.
- 외부 글꼴·CDN·외부 스크립트를 쓰지 않습니다. CSP는 `self`만 허용합니다.

### 기록 관리(기존)

- 역할: 담당, 파트장, 관리자. 확정·종결은 파트장 이상, 연한 전 파일 삭제와 삭제 보류는 관리자만.
- 보존연한 만료 시 본문·파일을 지우고 목록·이력은 남깁니다. 이력은 추가만 되는 SHA-256 체인으로, 행 변조가 화면에 표시됩니다.
- 첨부 원문은 열지 않습니다. 위치만 남기고, 사용자는 자기 PC의 나스카로 엽니다.
- 내부 백업과 복구 대조, 삭제 작업 큐, 계정 관리.

## 로컬에서 실행

.NET 10 SDK가 필요합니다.

```bash
dotnet run --project src/AuditRecord.App --urls http://127.0.0.1:47321
```

개발 환경(`DOTNET_ENVIRONMENT=Development`)은 예시 모드로 가짜 건 둘을 넣습니다. 로그인 값은 실행 폴더의 `var/data/demo-access.local`에만 있고, 문서나 화면에 다시 적지 않습니다.

운영 모드로 처음 켜면 `/account/setup`에서 관리자 한 명을 만듭니다. 가입 페이지는 그 다음에 닫힙니다.

기존 데이터베이스(v1)는 처음 켤 때 자동으로 등록번호가 소급 채번됩니다(연도별 등록 순).

## 배포

`packaging/`의 안내와 스크립트를 사용합니다. 대상 Windows에는 .NET, Java, Python, Docker, Node를 설치하지 않습니다. 자체 포함 게시물과 `e_sqlite3.dll`을 같이 둡니다.

폴더 배치는 `감사기록/app`, `data`, `files`, `backup`입니다.

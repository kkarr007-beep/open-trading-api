# 감사기록

감사파트 전용 기록·징계기록 등재 프로그램입니다. Windows x64 서버 한 대에서 실행하고, 같은 내부망의 다른 컴퓨터는 브라우저로만 접속합니다. 실행 중 외부망을 부르지 않습니다.

화면은 할 일, 건 목록, 건 상세, 자료, 징계기록, 관리, 설정입니다.

이 저장소의 기본 설정은 운영 모드입니다. 예시 데이터와 예시 계정은 `Audit:Mode`가 `Demo`일 때만 만들어집니다.

## 간편 설치와 접속

서버에서 `scripts\간편설치.cmd`를 한 번 누르면 폴더를 만들고 프로그램을 켠 뒤 브라우저를 엽니다.

1. 서버 화면에서 접속 비밀번호 하나를 정합니다. 관리자 계정은 이때 같이 만들어집니다.
2. 서버의 내부망 주소를 파트원에게 알려 줍니다.
3. 파트원은 그 주소를 열고 **비밀번호만 눌러** 들어옵니다. 로그인 이름은 묻지 않습니다.

역할을 나눠 써야 하면 로그인 화면의 `계정 이름으로 들어가기`로 계정별 로그인을 씁니다. 접속 비밀번호는 설정 화면에서 관리자가 바꿉니다. 다섯 번 틀리면 15분 쉽니다.

## 징계기록 등재

한 줄에 아래 항목을 담습니다. 목록, 상세, CSV의 머리글이 모두 같습니다.

순번 · 사번 · 성명 · 부서 · 직위 · 위반일자 · 위반내용 · 관련규정 · 징계종류 · 징계일자 · 징계기간 · 결정기관 · 근거문서번호 · 상태 · 비고 · 등록일자 · 담당자

- 순번은 등재할 때 자동으로 매겨지고 이후 바뀌지 않습니다.
- 목록의 성명은 일부를 가립니다. 상세를 열면 열람 이력이 남습니다.
- **감사번호로 감사 건과 잇습니다.** 등재 화면의 `감사 건 연결` 칸에 감사번호(예: `2026-01-01`)를 고르면 그 건의 상세에 `연결된 징계기록`으로 나타납니다. 건 제목으로도 찾습니다.
- 보존 만료가 오면 성명과 위반내용은 지우고 순번·날짜·대장 줄은 남깁니다. 삭제 보류 중이면 건너뜁니다.
- 파트장과 관리자만 봅니다. CSV 내려받기는 관리자만 합니다.

## 자료

- 파일을 고르면 이름·확장자·크기를 그대로 보여 줍니다. 표시 이름 칸이 비어 있으면 파일 이름을 넣어 둡니다.
- 표시 이름에 확장자가 없으면 올린 파일의 확장자를 붙입니다. 내려받은 파일이 Windows에서 제 프로그램으로 열립니다.
- 내려받기는 확장자에 맞는 형식을 보냅니다(pdf, docx, xlsx, pptx, hwp, zip 등). 브라우저가 실행할 수 있는 내용은 형식을 숨기고 내려받기만 합니다.
- 프로그램은 나스카 암호문을 풀지 않고 내용을 읽지 않습니다.

## 화면

- 맥과 아이폰의 결을 따릅니다. 넉넉한 여백, 둥근 모서리, 흐린 유리 머리말, 입체 단추.
- 입력창과 단추는 한 줄에 나란히 둡니다.
- 찾기 줄은 스크롤해도 화면 위에 붙어 있습니다. 표 머리글은 표 안에서 멈춰 섭니다.
- 라이트·다크·시스템 세 가지 화면 모드. 고른 값은 그 브라우저에만 저장합니다.
- 글꼴과 스크립트는 이 서버 것만 씁니다. 인터넷 글꼴과 외부 스크립트를 쓰지 않습니다.

## 로컬에서 실행

.NET 10 SDK가 필요합니다.

```bash
dotnet run --project src/AuditRecord.App --urls http://127.0.0.1:47321
```

개발 환경(`DOTNET_ENVIRONMENT=Development`)은 예시 모드로 가짜 건 둘과 징계기록 셋을 넣습니다. 접속 값은 실행 폴더의 `var/data/demo-access.local`에만 있고, 문서나 화면에 다시 적지 않습니다.

운영 모드로 처음 켜면 `/account/setup`에서 간편 설치를 합니다. 그 화면은 서버의 `127.0.0.1`에서만 열리고, 설치를 마치면 닫힙니다.

이전 버전의 데이터베이스는 처음 켤 때 자동으로 옮깁니다. 옛 징계기록(누가·언제·어디서·무엇을·어떻게·왜)은 등재 항목으로 옮기고, 어떻게·왜는 비고로 합칩니다.

## 배포

`packaging/`의 안내와 스크립트를 사용합니다. 대상 Windows에는 .NET, Java, Python, Docker, Node를 설치하지 않습니다. 자체 포함 게시물과 `e_sqlite3.dll`을 같이 둡니다.

폴더 배치는 `감사기록/app`, `data`, `files`, `backup`입니다.

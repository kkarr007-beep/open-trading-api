# 사내 도구 보관

사내 PC 에서 내려받아 쓰는 단일 파일 도구를 여기에 둡니다.
외부 통신을 하지 않으므로 내부망에서 그대로 쓸 수 있습니다.

## 사규 관리 시스템 v4

| 받을 것 | 쓰는 법 |
|---|---|
| [`sagyu-v4.html`](sagyu-v4.html) | 파일 하나만 받아 두 번 누르면 열립니다. 가장 간단합니다. |
| [`sagyu-v4-launcher.zip`](sagyu-v4-launcher.zip) | 압축을 풀고 「사규관리 열기.bat」 을 누르면 주소창 없는 창으로 열립니다. 자료는 같은 폴더의 `appdata` 에 쌓여 폴더째 옮길 수 있습니다. |

받는 방법 : 파일 이름을 누른 뒤 오른쪽 위 **Download raw file** 단추

### 알아두실 것

- 설치가 필요 없습니다. 관리자 권한도 필요 없습니다.
- 등록한 사규·메모는 브라우저가 PC 안에 보관합니다. 서버로 나가지 않습니다.
- `sagyu-v4.html` 을 그냥 두 번 눌러 쓰시면, 자료는 그 PC 의 브라우저 안에 쌓입니다.
  `.bat` 으로 여시면 자료가 같은 폴더의 `appdata` 에 쌓여 백업·이전이 쉽습니다.
  **두 방식은 자료를 따로 보관하므로 한 가지로 정해 쓰십시오.**
- Edge 또는 Chrome 으로 여십시오. 판이 낮으면 화면이 어긋날 수 있습니다.
